# NITRO Client (Fabric, MC 1.21.4)

Modules: AutoTotem, AnchorMacro, CrystalAura (Combat) | StorageESP, Freecam (Render) | NameHider (Misc)

Build:  gradle wrapper && ./gradlew build   -> build/libs/nitro-client-1.0.0.jar
Dev:    ./gradlew runClient

GUI (Right Shift): tabs on top, module list left, settings drawer right.
LMB select, switch/RMB toggle, wheel scroll, drag top bar to move.
Bind a key with the Bind button in the drawer (Esc/Backspace clears).
